🏥 Medical Imaging Viewer - Demo

⚠️ Note: This application loads DICOM and TIFF medical images locally in your browser.

To test the viewer:
  1. Open index.html in your browser
  2. Upload DICOM (.dcm) or TIFF (.tif) files
  3. Use the controls to navigate and adjust images

Keyboard Shortcuts

↑/W       - Previous slice
↓/S       - Next slice
+/=       - Zoom in
-/_       - Zoom out
R         - Reset view
I         - Invert colors
Ctrl+Wheel - Zoom
Wheel     - Navigate slices
Right-drag - Window level/width

Features Included

  • ✅ Drag-and-drop file upload
  • ✅ DICOM metadata extraction
  • ✅ Multi-slice navigation
  • ✅ Window level/width adjustment
  • ✅ Zoom & pan
  • ✅ 16-bit grayscale support
  • ✅ Auto-series detection
  • ✅ Thumbnail film strip
  • ✅ Heatmap overlay support
  • ✅ 3D volume rendering (WebGL)
  • ✅ PHI privacy protection

Browser Requirements

  • Chrome/Edge 90+
  • Firefox 88+
  • Safari 14+
  • WebGL support (for 3D features)
